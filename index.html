    结果怎么读

    • 已注册：站点返回 2xx 且没有命中"用户不存在"的特征，通常说明该用户名存在。
    • 未注册：状态码命中站点的"不存在"规则（404/错误码），或页面里出现站点约定的错误文案。
    • 无法判断：命中 Cloudflare 等 WAF 人机校验、超时、连接失败，或用户名不满足该站点规则（如只允许 4–12 位字母数字）。
    • 人工复核：拦截页通常是因为云函数的机房 IP 被风控，程序无法自己通过人机验证。点开那一行的「复核 →」，用你自己的浏览器打开确认，回来标成已注册 / 未注册即可 —— 标记会存在本机，重新检测时自动带出，并计入统计与导出。
    • 让服务器代看：本地打不开时，可以让云端出口再取一次这个页面，把服务端读到的标题、简介、正文摊在你面前。取到了就据此判断；取不到会如实说明被什么拦住（人机校验 / 网络封锁 / 限流 / 跳登录页），不会拿拦截页冒充真实资料。
    • 打不开：如果你的网络（比如国内直连）访问不了该站点，就标「打不开」。它仍计入「无法判断」、不会变成"未注册"，只是不再占用待复核队列 —— 看不到不等于没注册，工具不替你猜。
    • 结果只是"某个时刻该 URL 的响应"，不代表账号归属，也不保证与站点真实状态一致；部分站点有频率限制。
